# Использование ИИ при разработке

## Инструменты

- Claude Code (модель Claude Opus 5.5) — ассистент разработки в терминале.

## ЛР 1, этап А

Ключевые решения, принятые с обоснованием (а не просто сгенерированные):
- dataclasses + явная валидация вместо Pydantic, чтобы было видно, где выполняется проверка и что аннотации её не заменяют;
- `content_hash` по нормализованному UTC-времени: одинаковый момент в разных часовых поясах — дубликат, а не конфликт;
- `used=true` с пустым описанием не отклоняется при приёме, а будет проверяться анализатором (этап Б).

## Ограничения

- Все данные синтетические, сгенерированы скриптом; реальных работ студентов в репозитории нет.
- Код, предложенный ИИ, проверен тестами (`pytest`) и ручным запуском CLI.
